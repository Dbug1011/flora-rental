# Flora staff guide

The Google Sheet is our booking system. **Always use Flora menu → Open staff panel** to change bookings.
Typing directly into booking dates or statuses skips the availability check (the Sheet warns you if you try).

## Daily

1. Open the Sheet → **Flora → Open staff panel**.
2. **Today & upcoming** shows holds waiting for review, pickups and returns in the next 7 days, and **overdue** dresses.

## When a customer messages a booking code (FL-XXXXXX)

1. Panel → **Find a booking** → type the code → **Load**.
2. Check the Facebook account that messaged matches the **Facebook name** on the booking and looks active and real.
   - OK → **Approve account** (paste their profile link if you like).
   - Not OK → **Reject**, then **Cancel booking** to release the dates.
3. Send payment instructions in Messenger (manual).
4. When the deposit **actually arrives** in the account (not just a screenshot) → **Record verified deposit**.
5. **Confirm (rechecks availability)**. Then message the customer that the booking is confirmed.
   - If the hold already expired, tick **"I reviewed this late payment"**. The panel rechecks the dates; if a dress was
     taken meanwhile it will refuse — offer other dates or refund.
   - Need more time before payment? **Extend hold**.

A website request is **not** a booking until it shows **Confirmed**.

## Facebook or walk-in bookings

Panel → **New Facebook / walk-in booking**. Fill in the customer, dresses, pickup date and days. It uses the same
availability check as the website; if a dress is taken nothing is saved. Tick **Deposit already received and verified**
only if the money is in.

## Pickup day

1. Check the customer's original government-issued photo ID, then hand it back. **Do not photograph or keep IDs.**
2. Customer signs the rental agreement.
3. Check the dress and accessories together → **Record pickup** (per dress or ALL) with condition notes.
4. **Record rental payment** for the rental fee received. (Never put deposit money here.)

## Extensions

Customer asks for more days → **Approve extension** with the number of extra days. It checks the next bookings and
adds ₱100 per extra day to the rental total. If it refuses, the dress is booked right after.

## Return day

1. **Record return** per dress (partial returns are fine — the rest stay "out").
2. **Save inspection note** describing condition. Normal wear is not damage.
3. Needs extra cleaning or repair → **Block dates** for that dress. It warns if the block overlaps a booking.
4. **Record refund**: deductions (with a written reason) + refund amount. Deductions + refund can't exceed the verified deposit.

## Cancellations

**Cancel booking** releases the dates. Refunds follow the cancellation policy and are recorded with **Record refund**.

## Other

- To end a cleaning/repair block early, untick **Active** on its row in *Blocked Dates* (accept the warning).
- To add or edit a dress, edit the **Catalog** tab (each physical dress has its own Item ID). Tick **Published** only when it
  has a price, actual photos and measurements. Changes show on the website within about a minute.
- Never share the Sheet publicly or paste customer details into group chats.
